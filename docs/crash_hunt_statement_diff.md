## CH-01: `List[Cell, 4096]` (the one cell collection, `l4096_b2048`)

The setter and the appender take the cell as `O.Words{vws, vn}` and refuse a length other than the cell's 2048 bytes.

```
old  def l4096_b2048_api_set_flag(-ws: Array<U32>, +n: U32, +i: U32, -v: O.Words)
       -> {Pair.snd(O.Words, Bool, set(O.Words{ws, n}, i, v)) == U32.is_lt(i, (U32.div(n, 2048))) : Bool}
new  def l4096_b2048_api_set_flag(-ws: Array<U32>, +n: U32, +i: U32, -vws: Array<U32>, +vn: U32)
       -> {Pair.snd(O.Words, Bool, set(O.Words{ws, n}, i, O.Words{vws, vn}))
             == Bool.and(U32.is_lt(i, (U32.div(n, 2048))), U32.is_eq(vn, 2048)) : Bool}

old  ... api_set_rejected(..., -v: O.Words, +e: {U32.is_lt(i, (U32.div(n, 2048))) == False{} : Bool}) -> {set(.., v) == (O.Words{ws, n}, False{})}
new  ... api_set_rejected(..., -vws, +vn, +e: {Bool.and(U32.is_lt(i, (U32.div(n, 2048))), U32.is_eq(vn, 2048)) == False{} : Bool})
                                                    -> {set(.., O.Words{vws, vn}) == (O.Words{ws, n}, False{})}

old  ... api_append_flag(-ws, +n, -v: O.Words)   -> {flag == U32.is_le(((U32.div(n, 2048)) + 1 : U32), 4096)}
new  ... api_append_flag(-ws, +n, -vws, +vn)     -> {flag == Bool.and(U32.is_le(((U32.div(n, 2048)) + 1 : U32), 4096), U32.is_eq(vn, 2048))}
```

The old statements said the flag did not depend on the argument; that was the defect (a cell of any length was accepted and copied by its
own length). The new statements are exact (flag = guard), and `api_set_rejected` / `api_append_rejected` now cover every refused argument
(a weaker hypothesis, a conclusion for more cases). The read-back laws of the cell collection (`api_read_set`, `api_read_set_word`,
`api_view_set`) keep their printed text: their hypothesis is the index test and the cell has the length 2048 they already state.
The witnesses (`e2e/l4096_b2048_api_witness_generated.bend`) apply the new statements to concrete objects (`vn = 2048`).

## CH-04: `n + 1 <= N` wrapped at n = 2^32 - 1

For every list whose count can reach 2^32 - 1 (bit lists, byte lists of one-byte elements, element-array lists, cached lists) the guard is
`n < min(N, 2^32 - 1)`. A same-text fix does not exist: the old text computes `(n + 1 : U32)`, which is 0 at that count; no definitional
helper keeps the printed statement and the corrected meaning (the statement is the guard's text). Lists of elements of two or more bytes
(`n < 2^31`) keep their old guard and their old statements. Equivalent for every n below 2^32 - 1, stronger at n = 2^32 - 1.

```
old  bits2048_api_append_flag       == U32.is_le((n + 1 : U32), 2048)
new  bits2048_api_append_flag       == U32.is_lt(n, 2048)
old  l16_Deposit_api_append_flag    == U32.is_le((n + 1 : U32), 16)
new  l16_Deposit_api_append_flag    == U32.is_lt(n, 16)
old  l1099511627776_Validator_api_append_flag == True{}                 (limit 2^40: no guard at all)
new  l1099511627776_Validator_api_append_flag == U32.is_lt(n, 4294967295)
```

The lists with a limit above U32 used to have the guard `True{}` and their `append_rejected` statements were vacuous (no witness); the
new `append_rejected` statement is satisfiable (n = 2^32 - 1), is witnessed (`l1099511627776_Validator_api_append_rejected_witness`, the one
added statement) and is proved.

Proof support: `bits_view.bend`'s `n1` and `hk_of` take `n + 1 <= c`; the new lemma `lt_le1(n, c, ha: n < c) : n + 1 <= c` (generated by
`codegen/proofs/collections/bit_list_set_view.py`) derives it. `proofs/obj/capi.bend`'s `guard` is `U32.is_lt(n, 4294967295)`; the other
cached lists substitute their own limit. `codegen/proofs/laws/cached_root_laws.py`'s append template states `n < G`.
