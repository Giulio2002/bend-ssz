# Decode window (CH-06): the statements that change

`X_decode(buf, size)` refuses a window that is not inside the buffer: it answers `(buf, None{})` when `size > B.size(buf)` (compared as a
U32 against the buffer's size field, so nothing wraps, and with no size cap) and is `X_decode_in(buf, size)` otherwise. `X_decode_in` is the old
body of `X_decode` (`X_built(size, X_ok(buf, 0, size))`); `X_dwgo` / `X_dwin` are the guard (`types/<Name>_decode_ssz_generated.bend`, written by
`codegen/impl/typed_object_runtime.py` for every one of the 240 names). `X_decode_checked` is unchanged (it also tests the storage and the 2^31 bound,
which `agent/size-limit` removes; its `X_dchw` calls `X_decode`).

Nothing frozen changes: `tools/verify_frozen.py` passes WITHOUT `--update` (42 files, 4 statement roots, 1,915 statement_defs files), because no frozen
statement reaches a decoder. `frozen.lock.json` is untouched.

## 2. New laws (statements that did not exist)

`proofs/obj/decode_window_library_generated.bend`: `bsz(buf)` (the size field), `bool_cmp_refl`, `cmp_refl`, `le_refl(x): U32.is_le(x, x) == True{}`.

For each of the 240 decoders, `proofs/obj/decode_window_<Name>_generated.bend` (generator `codegen/proofs/laws/decode_window_laws.py`):

| law | statement |
|---|---|
| `<X>_win_none(buf, m, h)` | `h: X_decode_in(buf, m) == (buf, None{})` gives `X_decode(buf, m) == (buf, None{})`, for every window |
| `<X>_win_none_f(buf, m, hf)` | the same with `hf` a function of the buffer (a free buffer variable is used once) |
| `<X>_win_some(buf, m, r, hle, h)` | `hle: U32.is_le(m, bsz(buf)) == True{}`, `h: X_decode_in(buf, m) == r` give `X_decode(buf, m) == r` |
| `<X>_win_out(buf, m, hgt)` | **outside the buffer the result is None**: `hgt: U32.is_le(m, bsz(buf)) == False{}` gives `X_decode(buf, m) == (buf, None{})` (also when an off + size would wrap 2^32) |

## 3. The same statement, a new proof

339 laws in 249 generated modules keep their statement exactly (on `X_decode`) and have a new proof: the old proof moved to a law `<name>_in` whose
statement is the same with `X_decode_in`, and the law itself follows from `_in` by `X_win_none` / `X_win_none_f` / `X_win_some` (`DWL.le_refl(n)` for a buffer whose
size field is the window itself, `X_decode(BF(t, n), n)`). Laws over a literal window and a buffer of that literal size are untouched: the guard evaluates.
The wrapping is `codegen/proofs/support/decode_window.py`, applied by `runtime_file_split.rewire` to every generated module.
