# BeaconState benchmark

Run from the repository:

```sh
.venv/bin/python benchmarks/run.py --type BeaconState --case all --samples 5
# Select one official fixture:
.venv/bin/python benchmarks/run.py --type BeaconState --case case_0 --samples 5
```

Requires Go 1.25.5, pinned Bend/Bun paths and requirements.txt dependencies.
The initial completed results are retained in results.json and RESULTS.md.
They came from the isolated snapshot identified in source.json; the codec
contents match this publication. The scripts here adapt only repository paths.

Five official mainnet Fulu fixtures, 0–8 validators, about 2.74 MB each.
Exact bytes and official roots checked before timing. Named native APIs;
compilation, files, input conversion and validation are outside the timer.
Allocating serialization and fresh deserialization; uncached state roots.
Bend 2.0.16 compiles to JS on Bun 1.4.2 with --smol. Go uses fastssz 0.1.4
via go-eth2-client 0.27.2 (generated by fastssz 0.1.3), GOMAXPROCS=1.
Five samples, medians reported; Go each sample >=300ms, Bend one full call.
GC enabled, no forced collection. Backends run sequentially; their order
alternates between fixtures. Shared-machine load makes these exploratory
figures, not controlled production measurements. No production-sized registry
claim is made. results.json values are milliseconds per operation, not throughput.

The subsequent autoresearch score is sequential deserialize time only across
all five fixtures, with fresh input each sample and protected full acceptance.
