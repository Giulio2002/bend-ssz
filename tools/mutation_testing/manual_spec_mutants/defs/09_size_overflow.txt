## 32-bit size limits (SSZ: a serialized vector, list or container must be below 2**32 bytes; no wrap-around in length arithmetic)
=== s01-size-overflow
type: bitlist_513,progbitlist,FuluAttestation,FuluPendingAttestation
ops: root,encode
file: src/obj.bend
spec: the byte count of a Bitlist of n bits is ceil(n/8) for every n (no 32-bit wrap)
fault: ceil(n/8) is computed as (n + 7) >> 3 in 32-bit arithmetic (wraps above 2^32 - 8)
why: the textbook formula, overflowing for huge bit counts
-def bits_nbytes(+nbits: U32) -> U32: (U32.shrn(nbits, 3n) + U32.shrn((U32.and(nbits, 7) + 7 : U32), 3n) : U32)
+def bits_nbytes(+nbits: U32) -> U32: U32.shrn((nbits + 7 : U32), 3n)
